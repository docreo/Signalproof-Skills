# Signalproof Workbench RD2 R6 - G1 Version Legibility Requirement

**Date:** 2026-08-21  
**Status:** OWNER REQUIREMENT / R6-G1 ACCEPTANCE INPUT  
**Work stream:** Signalproof Workbench GUI RD2

## Owner requirement

The Workbench version/build identity must be clearly legible in the Workbench viewer at normal desktop scale.

This is part of R6-G1 UX acceptance, not a deferred cosmetic item.

## Acceptance interpretation

The R6-G1 candidate must preserve truthful version/build identity while improving its visual legibility through sufficient contrast, font sizing, spacing, and placement against the dark Signalproof interface.

The version/build text must:

- remain visible without requiring hover, resize, or special interaction;
- be readable at normal Windows desktop scaling;
- not be obscured by nearby controls, clipping, or low-contrast charcoal-on-black treatment;
- remain subordinate to the primary conversation UI while still being unmistakably readable;
- report the actual candidate identity rather than a fabricated provider/runtime/version state.

This requirement joins the existing R6-G1 UX housekeeping gate covering conversation gutters, readable width, message rhythm, composer polish, mature scroll semantics, and regression preservation.
