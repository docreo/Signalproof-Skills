# Signalproof Router — Learn Integration Acceptance

## Required behavior

1. Material reusable-lesson extraction after completed work routes to Learn.
2. Ordinary successful tasks do not automatically route to Learn.
3. Closeout remains the milestone-continuity gate; Learn performs deeper extraction only when warranted.
4. Unresolved factual truth remains Investigate/Verify territory.
5. Learn cannot promote observations directly to Active doctrine.
6. Learn cannot bypass existing-intelligence checks, acceptance tests, governance, or human approval.
7. Documentation-only outcomes may route Learn -> Document rather than forcing a new skill.
8. Weak generalization evidence may route Learn -> Research.
9. Learn remains distinct from Research, Evaluate, Document, Verify, Review, and Closeout.
10. Smallest sufficient route, STOP conditions, and authority separation remain preserved.

## Actual result

- 10/10 required behaviors PASS.
- 0 fail conditions.

## Non-claims

- Router selection does not activate, modify, or approve a skill/policy.
- Learn is routable only because canonical main already marks `signalproof-learn` Active after PR #55.
