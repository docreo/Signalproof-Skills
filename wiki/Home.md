## What this wiki is

This is a public explanatory layer. It provides context and orientation, but it does **not** replace canonical repositories, release artifacts, governed registries, technical evidence, or product-specific documentation.

For Signalproof Skills, the protected `main` branch, `SKILL-REGISTRY.md`, `GOVERNANCE.md`, and the individual active skill files remain authoritative for public skill-suite state.

## Core thesis

AI capability is increasing faster than most individuals and organizations can responsibly absorb it. More models, agents, automations, integrations, and applications do not automatically create better outcomes.

Signalproof focuses on the human operating system around those capabilities: clarity, authority, boundaries, readiness, evidence, recovery, continuity, evaluation, and deliberate adoption.

The objective is not maximum automation. The objective is **useful human-AI capability under meaningful human control**.

## Public boundary

This wiki intentionally excludes credentials, private customer information, private conversation history, unreleased security details, proprietary implementation details not intended for release, and unnecessary personal identifiers.

Public documentation should explain enough to be useful without weakening safety, privacy, ownership, or governance.
