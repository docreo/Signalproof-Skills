# Format routes

Use planning routes, not claims that bundled renderers exist. Load only the applicable row and an inspected project engine if available. This public pack supplies instructions/forms, not private engines or media.

| Format | Plan and protected behavior |
|---|---|
| Talking head / concept short | One idea, grounded hook, visible face/gestures, readable captions, complete payoff. Use SFX-only or approved music variant. |
| Interview / spotlight | Identify speaker, preserve meaning, map captions to speaker turns, avoid face overlays. |
| Event highlight | Map moments to event story; preserve chronology where relevant; use licensed B-roll and approved identification. |
| Rant / long talk | Preserve declared finished-mix or voice mode; use chapters and sparse supporting effects. |
| Explainer | Narration-first cue sheet, sourced factual cards, relevant B-roll, chapters, final takeaway. |
| Mini lesson | One learning goal, explanation/example/practice, takeaway; supplied series context only. |
| Slide promo / lesson | Time moves/highlights to narration; preserve legible supplied slides and diagrams. |
| Music video | Approved song timeline, beat/phrase map, shot list; mute unrelated audio unless authorized. |
| Fiction / story world | Supplied canon, names, imagery, art direction; no unrelated corporate brand layer. |
| Split / ladder | Propose coherent episodes/shorter cuts; preserve bookends and budget wrappers; obtain specific plan approval. |
| Multiple orientations | Shared EDL/cue IDs, shot-aware crop and native layout; verify each orientation. |
| Generated / 3D | Read generated-shots.md; storyboard and test before long renders; verify backend readiness separately. |
| Timestamp fix | Preserve approved ranges; re-render invalidated ranges where practical; verify final file. |
| Extras | Captions/thumbnails/chapters/descriptions from accepted content; no invented claims or implied publishing. |

An optional ladder is one roughly eight-minute breakdown, roughly two-minute story cuts, and several roughly thirty-second clips. These are project choices, not quotas; fit source, wrappers, and scope. Check current platform specifications only when platform compliance is part of the job.

Use installed public media specialists for narrow responsibilities when available instead of copying their doctrine. VideoCraft coordinates words, plan, EDL, protected state, and acceptance. Missing optional specialists do not block this self-contained workflow.
