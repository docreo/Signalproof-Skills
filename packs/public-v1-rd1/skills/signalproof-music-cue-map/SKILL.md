## Workflow

1. Identify authorized audio, lyrics, images, and intended story without distributing private masters or project narratives.

2. Measure candidate tempo, beat times, and energy changes with an available approved tool; verify ambiguous rhythm by listening.

3. Mark actual section and lyric times for each repetition. Do not obtain later chorus timings by blindly offsetting the first.

4. Write the current project's arc and map each visual to a source moment. Mark visual additions as editorial proposals.

5. Prioritize the semantic cue when snapping to a beat would change meaning. Record any timing tolerance as a project choice.

6. Inspect boundaries, repeated phrases, silent/instrumental sections, and the end before freezing the edit decision list.

## Result and verification
