**Status:** Owner-approved for public distribution, V1 RD1. Runtime-host validation remains pending.

## Workflow

1. Set the timezone, review window, planning horizon, authoritative systems, and allowed writes.

2. Review the completed period and upcoming calendar commitments; state coverage gaps.

3. Classify capture items into next action, project, waiting, scheduled, reference, or deferral proposals.

4. Find stalled projects, duplicate work, ambiguous ownership, overdue promises, and conflicting records.

5. Choose a small set of outcomes that fit actual capacity; name deferred work and dependencies.

6. Apply only authorized updates, read them back, and keep proposed follow-ups distinct from messages sent.

## Result and verification

Completed commitments; risks/waiting; stalled work; capacity-aware priorities; deferrals; verified updates and coverage gaps.

Return a scoped PASS, PARTIAL, FAIL, BLOCKED, or UNVERIFIED result when a verification claim is made. Report unavailable checks explicitly. Do not claim runtime-host validation, deployment, or delivery merely because this workflow produced a draft.
