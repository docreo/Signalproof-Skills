## HTML preview boundary

Preview is not execution.

Safe embedded HTML preview:

- renders current editor buffer;
- blocks privileged host calls;
- blocks external network by default unless policy allows;
- does not launch an external browser by default;
- does not call shell/process APIs;
- visibly reports blocked external assets when relevant.

`Open in Browser` is a later governed action, not required for G1C acceptance.

## Artifact / Bot editing loop

Required G1C interaction:

```text
Bot generates v1
-> owner opens
-> owner edits v2 Draft
-> owner asks Bot "make the header red"
-> Bot request references artifact/version/selection
-> proposed content preserves previous version
-> owner can apply/reject/revert
```

A full patch/diff engine may mature later, but prior generated content must remain recoverable.
