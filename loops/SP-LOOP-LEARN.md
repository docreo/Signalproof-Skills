# SP-LOOP-LEARN

**Status:** RD1 Candidate  
**Principal:** `signalproof-learn`

## Purpose

Turn completed evidence into the smallest justified reusable intervention without auto-promoting an observation into doctrine.

## Cycle

`SOURCE EVIDENCE -> EXTRACT LESSON -> CHECK EXISTING INTELLIGENCE -> GENERALIZABILITY TEST -> CHOOSE SMALLEST OUTPUT -> ACCEPTANCE TEST -> GOVERN / STOP`

## Contract

- Default maximum: **2 generalization passes** before recording UNKNOWN/research required.
- Preserve failed approaches and counter-evidence.
- Prefer documentation, regression test, checklist, policy, schema, loop, or existing-skill update over a new Skill when sufficient.
- Apply Skill Atomicity/Context Budget before expanding an existing Skill.
- New capability remains Candidate until tested/approved.

## STOP

STOP when evidence is incomplete, the lesson is local but being universalized, existing doctrine already covers it, a Skill would exceed budget without decomposition, or activation authority is absent.

## Evidence

Source milestone, lesson, generalizability class, existing-intelligence check, proposed durable output, acceptance condition, lifecycle status.
