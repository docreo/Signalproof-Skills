# SP-LOOP-RESEARCH

**Status:** RD1 Candidate  
**Principal:** `signalproof-research`

## Purpose

Iterate evidence gathering until the research question is sufficiently supported, contradicted, bounded, or explicitly unresolved.

## Cycle

`QUESTION -> SOURCE SEARCH -> SOURCE QUALITY/FRESHNESS -> EXTRACT CLAIMS -> CROSS-CHECK -> GAP TEST -> SYNTHESIZE / SEARCH AGAIN / STOP`

## Contract

- Start from a defined question and evidence threshold.
- Prefer primary/authoritative sources where appropriate.
- Each iteration must target a material unresolved claim or contradiction.
- Default maximum: **4 search/cross-check rounds** before reassessing the question/scope.
- More sources are not automatically more evidence; duplicate claims do not count as independent confirmation.
- Preserve contradictions and UNKNOWN rather than forcing closure.

## STOP

STOP when the question is answered to the required evidence class, sources cannot resolve the remaining uncertainty, the scope is drifting, or additional searches are repeating the same source set without new information.

## Evidence

Per round: query/gap, sources, freshness/quality, supported claims, contradictions, remaining unknowns, next decision.
