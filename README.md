# Signalproof Skills

Signalproof Skills is the public skill suite for human-controlled, evidence-backed AI collaboration.

The suite is being established as a governed, versioned system for helping people build with AI while protecting working systems, data, authority, recovery, and proof.

> Build signal. Cut noise. Leave proof.

This repository is currently in bootstrap status. The first governed skill baseline will be added through the protected pull-request workflow.
